# 📈 Аналитика S&P 500

Интерактивный анализ индекса S&P 500, 500 входящих в него компаний и истории цен их акций (2010–2024) в Google Colab.

## Что внутри

| Файл | Описание |
|---|---|
| `sp500_colab.py` | Весь код анализа (одна ячейка Colab) |
| `data/sp500_index.csv` | Значения индекса S&P 500 по дням, 2014–2024 |
| `data/sp500_companies.csv` | Справочник 502 компаний: сектор, отрасль, капитализация, город, сотрудники, вес в индексе |
| `data/sp500_stocks_part1-3.zip` | Ежедневные цены акций (Open, High, Low, Close, Adj Close, Volume), 2010–2024. Исходный CSV на 96 МБ разбит на 3 архива, чтобы уложиться в лимиты GitHub; код распаковывает и склеивает их сам |
| `requirements.txt` | Библиотеки Python |

## Что делает код

- **Панель показателей**: индекс, доходность, просадка, концентрация, ширина рынка
- **Индекс**: график с «подводной» диаграммой просадок, доходность по годам, коррекции больше 10%, цена пропуска лучших дней, «толстые хвосты», VaR/CVaR, режимы волатильности
- **Сезонность**: тепловая карта «год × месяц», дни недели
- **Структура рынка**: солнечная диаграмма секторов, тепловая карта рынка, концентрация, карта штаб-квартир США
- **Акции**: CAGR, волатильность, коэффициенты Шарпа и Сортино, бета, просадки, карта «риск/доходность», рейтинги
- **Анимация** «гонка лидеров» с 2015 года
- **Секторы**: ротация лидеров по годам, корреляции, кризис COVID-19, ширина рынка, кластеризация акций
- **Бэктест стратегий**: «купить и держать», трендовая по SMA-200, импульс, равновзвешенный портфель
- **Портфель Марковица** и **Монте-Карло**-сценарии индекса на год
- **Технический анализ**: свечи, SMA 50/200, полосы Боллинджера, MACD, RSI
- **Экспорт**: `sp500_report.xlsx` и интерактивный `sp500_report.html`

### Функции для экспериментов

```python
analyze_ticker('NFLX')                        # технический анализ акции
compare('MSFT', 'NVDA', 'GOOG')               # сравнение с индексом
radar('NVDA', 'AMZN', 'TSLA')                 # профиль акций
dca('NVDA', monthly=200)                      # регулярные взносы против покупки всего сразу
screener(min_cagr=0.2, sector='Технологии')   # фильтр акций
invest(['TSLA'], start='2019-01-02')          # «если бы я вложил $1000»
```

## Особенности данных

- История цен есть у 172 из 502 компаний (например, у Apple её нет).
- В выгрузке только нынешние участники индекса, поэтому результаты стратегий по акциям завышены (ошибка выжившего).
